# TBU Rotational Scan Structures

This directory contains the 24 relaxed structures used for the TBU rotational-energy profile.

- Dihedral: N2-C4-N1-C2
- Grid: -180 to 165 degrees in 15-degree increments
- Method: B3LYP/6-31G(d), PySCF/geomeTRIC
- Naming: `m` denotes a negative target angle and `p` denotes zero or a positive target angle
- XYZ comment: target angle, measured angle, electronic energy, and relative energy
